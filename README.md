# KREW

AI workforce for e-commerce brands: specialised AI agents that monitor the business, report, collaborate and propose actions that the owner approves on the web or on Telegram.

- `FRONT/`: web app prototype (React + TypeScript). All data is simulated. See `FRONT/README.md`.
- `docs/KREW_CONTEXT.md`: **start here.** The product, the domain model, the key flows and what the backend needs to do.

Backend: not started. Agents will run on Hermes Agent.

```bash
cd FRONT
npm install
npm run dev   # http://localhost:5173
```
